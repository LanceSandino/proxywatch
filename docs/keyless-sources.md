# Keyless and free-key discovery sources — 2026-10-14

Purpose: inventory of public sources ProxyWatch can use without an API key (and those needing a free key), each with a live reachability check from this workspace.

All checks ran on **2026-10-14** with `curl -m 15..60` and the User-Agent `ProxyWatch-research/1.0`. Only list files, repository metadata and API endpoints were requested. **No proxy, game or other discovered destination was visited.** Coverage numbers compare each list against a 2,529-host research inventory of school-proxy hostnames gathered from public sources in October 2026 (the 'union'). A match means the list contains the exact hostname or one of its parent domains. It shows that a list publishes the host, not what the host does.

This document builds on `docs/source-research.md`, which covers HN, Scope/Flarum, GitHub REST limits, Reddit, YouTube quota rules and DuckDuckGo.

## Recommended priority

1. Ingest **HaGeZi `doh-vpn-proxy-bypass`** as a reference list and a "known" flag. It covers 522 of 2,529 union hosts and updates several times a day.
2. Point the Bluesky adapter at **`api.bsky.app`**, which returns 200 without a key.
3. Add a JSON adapter for **CidCaribou/Games-4.0 `Proxy-Links/*.json`**: 92 new hosts, labelled by family.
4. Ingest **gjohnpaull `bypass-proxies.txt`** for its dense, curated school-proxy and rotating-apex entries. Its license is unclear, so treat it as a signal only.
5. Add a free **GitHub PAT** to enable code search for `links.json`/`links.md` files.
6. Add **urlscan.io search** (keyless at low volume, a free key for more) for live mirror hostnames.
7. Use **Invidious search** to find video IDs, plus a **YouTube Data API key** for their descriptions.
8. Add **Common Crawl / Wayback** subdomain enumeration for known rotating apex domains.
9. Add generic **Discourse/Lemmy/Mastodon-tag** adapters (cheap, low yield).
10. Skip or deprioritize: UT1 redirector (0 overlap), blocklistproject redirect, OISD, DuckDuckGo HTML (robots), Reddit without OAuth, public SearXNG, crt.sh wildcard.
